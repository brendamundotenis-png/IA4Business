# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## O que é este repositório

Base de conhecimento de negócio da Brenda para o projeto **IA4Business**. Não é um projeto de código — não há build, lint ou testes. Contém apenas documentação em Markdown usada como contexto para decisões, planejamento e discussões sobre o negócio.

## Estrutura

- `Projeto IA 4 Business - MD.md` — problema atual (gestão manual de estoque de ingressos via planilhas) e proposta de solução (autoatendimento + painel de vendedor).
- `Contexto/Negocio.md` — o que a MundoTênis vende, para quem, como monetiza, e limites estratégicos ("o que a empresa não pode fazer").
- `Contexto/Clientes.md` — perfil do cliente, motivações de compra, motivos de reclamação/churn, ordem de prioridades de valor.
- `Contexto/Sobre-mim.md` — quem é a Brenda e como ela quer receber respostas.

Antes de responder qualquer pergunta de negócio, estratégia ou produto, ler os arquivos de `Contexto/` relevantes ao invés de assumir.

## Idioma

Sempre responder em português.

## Estilo de comunicação (vale para toda interação neste repositório)

Definido em `Contexto/Sobre-mim.md`, aplica-se sempre, inclusive em decisões técnicas:

- Direto, objetivo, sem enrolação nem frases genéricas.
- Listas/tópicos em vez de texto corrido.
- Quando houver várias opções, mostrar só as mais relevantes — não todas.
- Questionar ideias que não fazem sentido ou que têm alternativa melhor; críticas diretas, sem suavizar.
- Se o pedido estiver vago ou faltar contexto, perguntar antes de assumir.

## Git

Nunca dar `commit`/`push` sem confirmação explícita da Brenda antes, mesmo após terminar uma edição.
